# Goohai 加载图库

在 ComfyUI 中搜索添加 **Goohai 加载图库**。这是独立的 V3 节点，输出 `image` 与字符串 `prompt`，不导入原服装、姿势或人像节点的模块，也不调用它们的接口。

- **prompt**：内置服装输出现有描述关键词；没有描述的素材、上传和“无”输出空字符串。自定义图片使用文件名第一个 `-` 后面的完整描述作为 prompt。
- **类型**：无、服装、姿势、发型、人像、上传。选择“无”时清空预览，输出 `None`；各图库保留分类、搜索及姿势多视角浏览。
- **随机**：打开后每次执行从当前类型的整个图库随机选择原图，执行结果同步回节点预览。上传和无类型忽略此开关。
- 随机设置齿轮可按图库类型选择参与随机的分类；取消的分类保留在普通浏览和上下分类切换中；仅“全部”范围启用随机或点击骰子时排除，手动选择具体分类后仍可随机。设置保存在节点目录的 `random_categories.json`，分享节点时一并携带即可共用设置。首次加载分类、打开齿轮或旧素材读取失败时清理失效分类并按需保存，新增分类默认勾选；正常切图复用已加载设置，不检测分类、不定时轮询，手动勾选后点击确定保存。
- 悬停预览显示左右箭头和“随机”按钮；箭头循环切换上一张、下一张，随机开关打开时箭头也随机切换。上传和无类型隐藏这些按钮。
- 预览无背景框，图像在节点现有预览区内等比例缩放、居中完整显示，底部显示原始宽高；切换图像或选择“无”均不自动改变节点尺寸。预览和按钮不显示悬停提示文字。
- **图像**：图库选择保留原始 ID；自己上传时显示文件名（包含上传子目录）。
- 悬停卡片显示“使用”和空心爱心，收藏后变为红色实心爱心；点击“使用”立即返回节点，执行时加载完整原图。
- 所有类型均支持拖入图像，自动切换为“上传”。上传模式也可点击按钮选择文件，文件由 ComfyUI 保存至 `input/GHIL`。
- 双击节点预览进入裁剪：左侧选择自由或固定比例，拖动框内移动选区，拖动边缘及四角调整大小；双击或回车确认，Esc 取消，切换图像时自动取消未确认的裁剪。裁剪结果用于预览和 image 输出，原素材不变；再次进入显示原图并恢复上次选框，设置随工作流保存且仅用于对应图像。确认裁剪后，下一次执行使用当前图像；后续随机选到其他图像时不套用旧裁剪。
- 裁剪模式左侧“自由”上方的“清除”恢复完整原图并退出裁剪。激活节点后，按 X（支持中英文输入法及大小写）仅清除该节点裁剪；运行工作流时自动确认当前选框，执行中更换图像时不套用旧选框。
- 四类图库的收藏统一保存在节点目录的 `favorites.json`，更换浏览器或清理浏览器数据不影响收藏；分享节点时携带此文件即可。首次加载对应图库时自动合并当前浏览器的旧收藏，保存成功后移除旧浏览器记录。读取收藏、刷新图库或修改收藏时，静默清理已删除或改名的图像记录；配置无变化则不写文件。正常切图复用已加载数据，无定时轮询。
- 选中节点后按 **S**，将当前预览图加入对应类型的收藏夹；重复按下只提示“已收藏”，不会取消。支持中英文及全角输入模式，输入框编辑时不触发；上传和无类型不收藏。预览顶部显示绿色爱心与半透明圆角提示，停留 2 秒后渐隐。快捷键仅由按键事件触发，不使用定时轮询。
- 收藏按钮与分类同排，点击显示收藏，再次点击恢复全部；页面省略介绍区和排行榜，直接浏览图库。
- 内置分类、“全部”和收藏页面保持竖版布局，不读取内置图尺寸；仅选择自定义分类时自动判断布局：横图超过半数时使用每行 4 张、3:2 图像区域，窄屏每行 2 张；否则保留原有竖版布局。图片完整显示，随机排序不影响布局判断。
- 所有图库首次加载 10 行，按当前窗口列数计算张数，滚动到底部时自动追加 10 行，无需点击“加载更多”。自定义图片在各大分类内按文件名数字顺序排列，不受子文件夹顺序影响；开启随机或点击骰子后使用随机顺序。
- 四类窗口标题统一为“GooHai · 对应类型图库”。服装顶部链接与图库右侧对齐；滚动时固定分类栏，搜索栏随页面滚动。“版权 · 致谢”在当前窗口弹窗显示，每次打开重新读取并渲染 `models/GHIL/costume/README.md`，修改后重新打开即可生效。正文链接在新标签页打开，插图以链接提供。
- 人像分类为全部人像、正脸参考、造型参考；上下方向键在内置分类、自定义分类与收藏之间循环切换。卡片悬停显示“使用”和收藏，不提供 PNG 下载按钮。

## 图库目录

图库不放进节点代码或 Git 仓库。当前本机素材已复制到 ComfyUI 的 `models/GHIL`：

```text
ComfyUI/models/GHIL/
  costume/
    data/costume-zh.json
    img/                 # 高质量 JPG 大图
    thumbs/              # 缩略图
  pose/
    data/pose-zh.json
    img/                 # 高质量 JPG 大图
    thumbs/
  hair/
    data/hairstyle-zh.json
    img/                 # 高质量 JPG 大图
    thumbs/
  portrait/
    data/portrait-zh.json
    img/                 # 高质量 JPG 大图
    thumbs/              # 原始缩略图
  自定义/
    服装/
      证件照女/
        001-卡其色西装 白衬衫 领带.jpg
      结婚登记/
        01.jpg
    发型/
    姿势/
    人像/
    thumbs/              # 自动生成的缩略图，按类型分目录，可删除后重建
```

自定义素材按 `自定义/类型/分类/图片` 存放，分类标签使用实际文件夹名，接在内置分类之后，收藏始终放在分类标签最后；节点上下方向键也包含这些分类。文件名（不含扩展名）按第一个 `-` 分成标题和描述；没有 `-` 时全部作为标题，prompt 为空。标题、描述和分类都可以搜索。新增、删除或重命名后重新打开图库即可更新，重启后同样会重新扫描。

自定义缩略图按需生成至 `models/GHIL/自定义/thumbs/类型/`，最长宽高为 400 × 500；再次浏览直接复用，原图修改后自动更新。高清预览和节点输出使用原图，生成缩略图不修改原素材。

自定义大分类支持子文件夹，例如 `自定义/服装/汉服/小分类/图片`。选择“汉服”后，搜索框前显示“全部”和子文件夹名的下拉菜单；更深层的图片归入第一级子文件夹。没有子文件夹时不显示下拉菜单。“全部”包含大分类下直接存放的图片。小分类仅用于图库筛选，节点分类和切图仍使用“汉服”等大分类；姿势、发型和人像同样适用。

发型图库当前使用 `comfyui-hairstyle-gallery` 提供的 893 张素材和 `data/hairstyle-zh.json` 索引；发型页面只保留中文、长度筛选、搜索、收藏和“使用”，自定义素材从上述目录读取。

人像图库复制自本机 `comfyui-portrait-gallery`，共 1,499 张，含 893 张正脸参考与 606 张造型参考。大图按原尺寸转为 JPG（质量 100、无色度抽样），缩略图保持不变，索引同步更新；不依赖原节点的接口或安装目录。其来源与许可说明沿用 `licenses/hair/` 中同一人像素材源的说明。

重启 ComfyUI 并刷新页面后使用。原参考节点目录保持原样；本节点运行仅依赖自身代码与 `models/GHIL`，删除参考节点不影响使用。旧工作流中的原节点需要手动替换为新节点。迁移到其他电脑时，另行复制整个 `models/GHIL`，仅复制本项目代码不包含素材。
